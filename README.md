# swe-foundry-site

Public website and release downloads for SWE Foundry.

The site is served by GitHub Pages from the `gh-pages` branch at <https://swe-foundry.syscake.it/>. Its source lives in `site/` of the SWE Foundry source repository; plugin releases (`swe-foundry-X.Y.Z.zip` with `SHA256SUMS` and `build-metadata.json`) are published under this repository's Releases.
